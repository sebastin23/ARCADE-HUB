# Arcade Hub 🎮
Mi hub de juegos.

- `index.html` → hub original (lista de tarjetas).
- `index-nuevo.html` → versión nueva tipo consola (carrusel, idiomas, temas). Para probarla, ábrela publicada en GitHub Pages.

## Añadir un juego
1. Guarda el juego como `<id>.html` en la raíz.
2. Añade un objeto a `games.js`.

## Publicar
Settings → Pages → Deploy from a branch → `main` / `(root)`.
