# Arcade Hub 🎮
Mi hub de juegos. Interfaz tipo consola con carrusel, pantalla de carga, idiomas (ES/EN), temas y sonido.

## Añadir un juego
1. Guarda el juego como `<id>.html` en la raíz.
2. Añade un objeto a `games.js` (nombre, emoji o `img`, etiquetas, colores).

## Subir a GitHub y publicarlo
1. Sube **el contenido** de esta carpeta a la raíz del repo (arrastra los archivos en "Add file → Upload files").
2. En el repo: **Settings → Pages → Deploy from a branch → main / (root)**.
3. En un minuto estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
